*wpb_map()* is an alias of [vc_map()](/devs/inner-api/vc_map). It accepts the same arguments and behaves identically.

```php
<?php wpb_map( $params ); ?>
```

See the [vc_map() documentation](/devs/inner-api/vc_map) for the full list of parameters, examples, and usage details.
