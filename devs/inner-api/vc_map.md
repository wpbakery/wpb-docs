*vc_map()* is an alias of [wpb_map()](/devs/inner-api/wpb_map). It accepts the same arguments and behaves identically.

```php
<?php vc_map( $params ); ?>
```

See the [wpb_map() documentation](/devs/inner-api/wpb_map) for the full list of parameters, examples, and usage details.
