# How to manage list of Google fonts

WPBakery Page Builder uses a specific array of Google Fonts available to Custom Heading element and element extensions for styling of heading part. It is possible to change the list of Google Fonts by applying filter `vc_google_fonts_get_fonts_filter` – it will return an array of Google Fonts list which can then be modified/rewritten.
