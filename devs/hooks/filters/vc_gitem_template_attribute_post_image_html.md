# vc_gitem_template_attribute_post_image_html

Filters the HTML output of a post's featured image in a grid item template.

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `$html` | string | The HTML markup for the post thumbnail, generated by `get_the_post_thumbnail()`. |

## Usage

```php
<?php
add_filter( 'vc_gitem_template_attribute_post_image_html', 'my_custom_post_image_html', 10, 1 );

function my_custom_post_image_html( $html ) {
    // Add a wrapper div around the post image
    return '<div class="my-custom-image-wrapper">' . $html . '</div>';
}
```
