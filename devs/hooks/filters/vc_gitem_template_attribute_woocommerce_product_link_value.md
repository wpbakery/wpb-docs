# vc_gitem_template_attribute_woocommerce_product_link_value

Filters the WooCommerce "Add to Cart" URL for a product displayed in a grid item template.

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `$link` | string | The "Add to Cart" URL generated by the `[add_to_cart_url]` WooCommerce shortcode. |

## Usage

```php
<?php
add_filter( 'vc_gitem_template_attribute_woocommerce_product_link_value', 'my_custom_product_link', 10, 1 );

function my_custom_product_link( $link ) {
    // Redirect to the product page instead of the add-to-cart URL
    return get_permalink( get_the_ID() );
}
```
