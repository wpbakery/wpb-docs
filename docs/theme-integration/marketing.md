# Theme Integration Marketing

There are following marketing rules divided into Do's and Don'ts you must follow if you have decided to integrate WPBakery page builder into your theme.

## Do's

- Link to WPBakery Page Builder ([https://wpbakery.com](https://wpbakery.com)) website from your item description page when mentioning WPBakery Page Builder
- Explain the difference between integrated and standalone versions of WPBakery Page Builder – [see description here](https://kb.wpbakery.com/docs/faq/wpbakery-vs-visual-composer)
- Use graphic materials available in this section for item description

## Don'ts

- State that customers will receive WPBakery Page Builder for free
- Promise official WPBakery support for the integrated version of WPBakery Page Builder
- Promise direct updates from WPBakery for the integrated version of WPBakery Page Builder
- Rename or hide WPBakery Page Builder brand in any way (remember that In-Stock license is not White Label)
- Share your Extended/In-Stock license key with your customers
- Forbid customers to purchase the standalone version of WPBakery Page Builder
