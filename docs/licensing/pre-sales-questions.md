# Pre-sales questions

Find answers to common questions about WPBakery Page Builder before purchasing a license.

## What is the difference between WPBakery Page Builder and Visual Composer Website Builder?

WPBakery Page Builder and Visual Composer Website Builder are separate products developed to work with WordPress.

WPBakery Page Builder is designed for creating and editing the content area of WordPress pages. Visual Composer Website Builder is a full website builder that allows you to build the entire website. Additionally, the two products differ in technology usage. WPBakery is based on shortcodes and jQuery, while Visual Composer has introduced newer technologies, such as ReactJS, and no shortcodes.

WPBakery Page Builder was previously called **Visual Composer Page Builder** before it was renamed in 2017.

Learn more about [the difference between the two products](https://kb.wpbakery.com/docs/faq/wpbakery-page-builder-visual-composer-page-builder/).

## Is WPBakery Page Builder compatible with my WordPress theme?

WPBakery Page Builder is designed to work with [properly coded WordPress themes](https://kb.wpbakery.com/docs/faq/does-wpbakery-page-builder-formerly-visual-composer-works-with-any-wordpress-theme/). Compatibility can also depend on how an individual theme is built and whether the theme includes custom WPBakery Page Builder integrations or modifications.

If WPBakery Page Builder is bundled with your theme, updates and support for that bundled version are provided by the theme author.

## Does WPBakery Page Builder work with other WordPress plugins?

Yes, WPBakery Page Builder works with all of the most popular WordPress plugins and can also be extended through third-party integrations and add-ons.

However, because WordPress plugins are developed independently, compatibility with every plugin cannot be guaranteed.

You can also extend WPBakery Page Builder with [WPBakery add-ons](https://wpbakery.com/addons/).

## Does WPBakery Page Builder include lifetime updates?

Yes, the WPBakery Page Builder offers free lifetime updates.

Manual updates remain available to license owners even after the included support period expires. One-click automatic updates from the WordPress dashboard require an [active or extended Support Plus license](https://kb.wpbakery.com/docs/preface/support-policy/).

See the [WPBakery Page Builder update documentation](https://kb.wpbakery.com/docs/getting-started/update/) for more information.

## Does WPBakery Page Builder include support?

Yes. Every WPBakery Page Builder license purchased directly from WPBakery includes one year of Premium Support. Premium Support includes access to the WPBakery support ticket system and supported features during the active support period.

After the first year, you can renew Premium Support manually or subscribe to Support Plus.

[Support Plus](https://kb.wpbakery.com/docs/licensing/support-plus-licensing/) includes additional benefits such as priority support, automatic renewal, Templatera, Easy Tables and WPBakery Loyalty Program discounts.

## Can I try WPBakery Page Builder before purchasing?

Yes. WPBakery Page Builder does not offer a downloadable free trial, but you can use the [WPBakery online demo](https://wpbakery.com/try/) to create a demo sandbox and try the plugin before purchasing.


## Is WPBakery Page Builder a one-time purchase?

Yes. WPBakery Page Builder is a one-time purchase, and there are no additional costs for using the plugin.

Optional services such as [Support Plus](https://kb.wpbakery.com/docs/licensing/support-plus-licensing/) are billed separately.
