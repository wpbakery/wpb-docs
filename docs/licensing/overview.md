# Licensing

This section will explain all you have to know about licensing for WPBakery Page Builder and point you to necessary resources. The most important thing you need to know about licensing of WPBakery Page Builder is that it uses GPL licenses starting from 20th of January 2018.

## License types

  <a href="/docs/licensing/regular-license" className="topic-card">
