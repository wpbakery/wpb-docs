# Multi-site licenses

WPBakery multi-site licenses allow you to use WPBakery Page Builder on several WordPress websites under one license plan. They are suitable for freelancers, developers and agencies managing multiple personal or client websites.

WPBakery offers two multi-site license options:

| **License** | **Number of websites** | **Suitable for** |
| --- | --- | --- |
| **5 Sites license** | Up to 5 websites | Freelancers, developers and small agencies |
| **10 Sites license** | Up to 10 websites | Agencies and teams managing a larger website portfolio |

Both are lifetime licenses. You pay once for the license and can continue using WPBakery Page Builder on the included number of websites.

## 5 sites license

The **5 sites license** allows you to activate WPBakery Page Builder on up to five websites.

The license can be used across your own websites, client websites, or a combination of both. Each activated website receives access to WPBakery Page Builder updates according to the update method available for the license.

## 10 sites license

The **10 sites license** allows you to activate WPBakery Page Builder on up to ten websites.

Like the 5 Sites license, it can be used for your own websites and client projects. It is intended for users who manage more WordPress installations and need additional activations under one purchase.

## Updates and support

WPBakery licenses include free plugin updates for the lifetime of the license.

With active support, the plugin can be updated directly from the WordPress dashboard. If the support period expires, license owners can continue downloading new versions and updating the plugin manually.

Each multi-site license includes one year of support. Support and the associated features can be renewed after the initial period.

## Managing website activations

License activations can be managed through the WPBakery Support Portal. If a website is moved to another domain or the license is no longer needed on a particular site, deactivate it before using that activation on another website.

A separate license is not required for a staging version of a licensed live website.

## Do I need 5 sites or 10 sites license?

Choose the license according to the number of websites on which you need to activate WPBakery Page Builder:

- Choose the **5 Sites license** if you manage up to five websites.
- Choose the **10 Sites license** if you manage between six and ten websites.
- If you need licenses for 20 or more websites, see the [WPBakery Agency Program](https://wpbakery.com/wpbakery-agency-program/).

View the available options and [purchase a WPBakery multi-site license](https://wpbakery.com/wpbakery-page-builder-license/).
