# Theme integration license

The **WPBakery Theme integration license**, previously called the **Extended License**, allows a WordPress theme developer to integrate WPBakery Page Builder into one theme.

A separate Theme integration license is required for each WordPress theme in which WPBakery Page Builder will be included.

**Who is the Theme integration license for?**

This license is intended for WordPress theme authors who want to offer WPBakery Page Builder as part of their theme.

It is not intended for users who want to install WPBakery Page Builder directly on their own or their clients’ websites. For direct website use, choose a [One site license](/docs/licensing/one-site-license) or one of the [Multi-site licenses](/docs/licensing/multi-site-licenses).

**How theme integration approval works**

After purchasing the Theme integration license, submit the theme integration request through the [WPBakery Support Portal](https://support.wpbakery.com).

WPBakery must approve the integration and convert the Theme Integration License into an **In-Stock License** before the theme is distributed with WPBakery Page Builder.

Theme developers must also follow the official [Theme integration documentation](/devs/theme-integration/technical) when adding WPBakery Page Builder to their theme.

**Updates and support**

The Theme Integration License includes:

- One year of use in a single WordPress theme
- One year of official WPBakery support
- Free WPBakery Page Builder updates

When WPBakery Page Builder is included with a WordPress theme, plugin updates and product support are provided by the theme author. Purchasing a theme that includes WPBakery Page Builder does not give the end user a separate direct WPBakery license.

To receive direct updates and support from WPBakery independently of the theme, the end user must purchase a separate WPBakery Page Builder license.

[View the available plans and purchase a WPBakery Theme integration license](https://wpbakery.com/wpbakery-page-builder-license/).
