# Theme license

Theme license (Extended license) allows the use of the item in one single website and receive updates for it.

You can purchase the it from [here](https://wpbakery.com/wpbakery-page-builder-license/) and see the other plans [here](https://wpbakery.com/wpbakery-page-builder-license/).
