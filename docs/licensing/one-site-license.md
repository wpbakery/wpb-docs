# One Site license

One Site License or Regular License is the most common type of licensing for WPBakery Page Builder. A regular license allows you to receive item updates on a single website.

You can purchase the Regular License from [here](https://wpbakery.com/wpbakery-page-builder-license/) and see the other plans [here](https://wpbakery.com/wpbakery-page-builder-license/).
