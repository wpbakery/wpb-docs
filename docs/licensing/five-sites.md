# 5 Sites

## test

A 5 Sites license allows using the plugin on up to 5 websites. All the websites on which the license is used will receive plugin updates. These licenses can be used on your own websites or on your client's websites.

You can purchase the 5 Sites License from [here](https://wpbakery.com/wpbakery-page-builder-license/) and see the other plans [here](https://wpbakery.com/wpbakery-page-builder-license/).
