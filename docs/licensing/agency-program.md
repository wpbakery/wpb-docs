# WPBakery Agency Program

The **WPBakery Agency Program** provides bulk WPBakery Page Builder licenses for agencies and businesses that need to use the plugin on 20 or more websites.

Agency license packs are available for 20, 30, 40, 50 and 100 websites. Custom plans are also available for businesses that need a different number of licenses.

Agency pricing is based on the number of licenses purchased. The current prices and available discounts are listed on the [WPBakery Agency Program page](https://wpbakery.com/wpbakery-agency-program).

If you need fewer than 20 licenses, see the [One site license](https://kb.wpbakery.com/docs/licensing/one-site-license/) or [Multi-site licenses](https://kb.wpbakery.com/docs/licensing/multi-site-licenses/).

## What is included?

Each WPBakery Agency Program license pack includes:

- Lifetime use on the number of websites covered by the selected pack
- Free WPBakery Page Builder updates
- One year of WPBakery support
- One year of access to WPBakery AI
- One year of access to the WPBakery Template Library
- Access to the WPBakery Agency Program
- Priority agency support

Agencies purchasing 50 or more licenses receive dedicated account management, with the level of service depending on the selected license pack.

Agency Program customers also receive a one-on-one onboarding call to go through the WPBakery setup and address their initial questions.

## Updates and support

Agency licenses are lifetime licenses purchased with a one-time payment. WPBakery Page Builder updates remain available for the lifetime of the licenses.

Each license includes one year of support, which can be renewed annually. While support is active, agencies have access to:

- The WPBakery support ticket system
- Automatic plugin updates
- The WPBakery Template Library
- WPBakery AI
- Typography features for Google and Adobe fonts

Agencies can also add a Support Plus subscription for priority support, Templatera, Easy Tables and access to the WPBakery Loyalty Program.

## Custom agency plans

If the standard license packs do not match the number of websites your agency manages, request a custom plan for the required number of licenses.

Visit the [WPBakery Agency Program](https://wpbakery.com/wpbakery-agency-program) to check current pricing, purchase a standard license pack, or submit an inquiry for a custom plan.
