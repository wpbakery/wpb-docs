***Since 4.1***

Starting from version 4.1.0 WPBakery Page Builder offers additional design controls for Row, Columns, Text block, Single image and Video block which can be found under element param window 'Design Options' tab.

Within Design Options it is possible to control:

- Margins, Paddings and Border for overall element or just left, right, top or bottom part
- Border style
- Border color
- Border radius
- Background color
- Background image and position style

## Per device

Since the 9.1 update design options can be set for one device at a time: select a device in the navigation bar and enable "Apply styles only for selected device type". The device starts with a copy of the current values. Read more in [Responsive settings](/docs/building-with-wpbakery/responsive-settings).

## Hide element

"Hide element" toggle at the top of the tab hides the element on your site, or only on the selected device when you edit per device.
