# WPBakery MCP

WPBakery AI MCP lets you connect an AI client that supports the Model Context Protocol (MCP) to your WordPress site. You can use it to create and edit WPBakery pages, templates, grid items, and presets with the elements available on your site.

## Requirements

- WPBakery Page Builder 9.0 or later
- WordPress 6.9 or later
- PHP 8.2 or later
- An active Support Plus plan
- The WPBakery AI plugin

## Connect your AI client

In WordPress, go to **WPBakery > WPBakery AI > MCP** and follow the connection instructions for your AI client. WPBakery AI MCP works with MCP-compatible clients such as Claude, ChatGPT, and Cursor.

## How it works

WPBakery AI MCP uses the elements registered on your site to build and edit content. It can use elements from your theme and add-ons as well as the built-in WPBakery elements.

WPBakery AI MCP does not manage plugins, themes, or users, and it cannot run PHP. Editing raw HTML, raw JavaScript, and code fields requires a user with the `unfiltered_html` capability.

For details on making custom elements work well with WPBakery AI MCP, see [WPBakery AI MCP for developers](/devs/wpbakery-ai/overview).
