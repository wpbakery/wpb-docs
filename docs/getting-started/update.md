# Update

The WPBakery Page Builder can be updated using any of these two methods:

## 1) Auto-updates

WPBakery Page Builder version offers automatic WordPress update mechanism. To use the automatic update option you must have a direct license for WPBakery Page Builder (with an active support tenure) and [activate it](./activation). When a new version of WPBakery Page Builder will be available, you should click "Update WPBakery Page Builder now" link under WPBakery Page Builder in WP Dashboard/Plugins page.

## 2) Manual updates

It is also possible to update WPBakery Page Builder manually. To perform it please follow these steps:

1. First, log in to [support.wpbakery.com](https://support.wpbakery.com)
2. Re-download the latest version from "Downloads" section and extract (unzip) it
3. Navigate to WPBakery Page Builder License tab in your WP Dashboard and deactivate your license
4. Now navigate to the Plugins menu in your WordPress admin area
5. Remove old copy of WPBakery Page Builder
6. Upload new version of WPBakery Page Builder
7. Activate WPBakery Page Builder license

:::warning
If WPBakery Page Builder came integrated into your theme, then ask your theme provider to update WPBakery Page Builder for you or [purchase license](https://wpbakery.com/wpbakery-page-builder-license/) directly from us to get free automatic updates.
:::

## What are the benefits of direct WPBakery Page Builder License

If you purchase a direct license for WPBakery Page Builder there are following benefits you receive:

- Access official customer support (opening support tickets are available only for direct license owners)
- Update WPBakery Page Builder directly from WPBakery
- Use WPBakery Page Builder with any theme (not just the one that got WPBakery Page Builder bundled)
- Manage your licenses at Support Portal
- Support your beloved page builder plugin for rapid development

You can purchase WPBakery Page Builder license [here](https://wpbakery.com/wpbakery-page-builder-license/).
