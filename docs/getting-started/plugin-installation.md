# WPBakery Page Builder plugin installation

WPBakery Page Builder is installed through the standard WordPress plugin installation process.

These instructions apply when you purchase WPBakery Page Builder directly and download the plugin package. If your WordPress theme includes WPBakery, follow the installation instructions from your theme author.

## Before installing WPBakery Page Builder

Locate the package downloaded after your purchase. If the downloaded archive contains documentation and other files, extract it first and locate the installable WPBakery Page Builder ZIP file.

Keep the plugin ZIP file compressed before uploading it to WordPress.

## Install WPBakery Page Builder

1. Log in to your WordPress dashboard.
2. Go to **Plugins → Add New Plugin**.
3. Click **Upload Plugin**.
4. Select the WPBakery Page Builder ZIP file.
5. Click **Install Now**.
6. Wait for WordPress to upload and install the plugin.
7. Click **Activate Plugin**.

WPBakery Page Builder is now installed and active on your WordPress website.

## Start using WPBakery Page Builder

Go to **Pages → Add New** and switch to WPBakery Page Builder to start creating your page.

You can review the available plugin settings under **WP Dashboard → WPBakery Page Builder**.

Congratulations, you are all set! To start creating visit **Pages → Add new** and switch over to the WPBakery Page Builder mode.
