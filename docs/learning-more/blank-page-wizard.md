# Blank Page Wizard

![Blank page interface introduced in 7.0 update](https://kb.wpbakery.com/wp-content/uploads/2023/08/blank-page-interface.png)

In the 7.0 release, the WPBakery Page Builder introduced an interface that allows you to select two types of pages before any content is added:

**Blank Page:** This is useful if you want to add content to a completely blank page that does not have a theme header, footer, or sidebar added.

**Theme Layout:** This is the default layout that is used by the theme to output its content.

The type of page layout can also be changed from the page settings option with the editor toolbar.
