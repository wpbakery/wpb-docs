## ***Since 5.0***

WPBakery Page Builder Template Library allows you to access beautiful predefined templates that have been created by WPBakery Page Builder team in collaboration with top-notch web design professionals. Template Library is being constantly updated by adding new templates that you can access with your direct WPBakery Page Builder license. Every template contains high-res free stock images that you are allowed to use in your projects (including commercial).

## Access Template Library

To access Template Library navigate to Template window in the top left corner of WPBakery Page Builder navigation bar and select **'Template Library'**. Template Library window will contain all templates that have been downloaded from the library *(by default it will contain no templates)*. To access library click **'Access Library'** button and wait for your WPBakery Page Builder connect to our template repository. Upon loading, you will see all templates available for download with the option to download or preview them.

To download templates click on **'Download Template'** within template preview and wait for it to be downloaded. Once you have downloaded your templates you must exit template library by clicking **'Exit Template Library'**. Your downloaded templates will now appear under Template Library tab in Templates window.

A quick step by step guide:

1. Open Template window;
2. Navigate to 'Template Library' tab;
3. Click 'Access Library';
4. Browse and Preview templates;
5. Download template;
6. Click 'Exit Template Library';
7. See downloaded templates in 'Template Library' tab in Template window.

**Important:** Make sure to have your [WPBakery Page Builder license](/docs/licensing) activated in order to download templates as these templates are available [exclusively for direct license owners](/docs/faq/what-are-the-benefits-of-direct-license-for-wpbakery-page-builder) with an [active support period](/docs/licensing/support-plus).
