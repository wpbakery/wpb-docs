Templates allow you to save predefined sets of elements as a template and then reuse it when you'll need it next time. By using templates you will be able to save tons of time in case you need to create a specific layout on and on – all you have to do is create your layout and save it, after that, you will be able to reuse it whenever you need it.

## Working with Templates

Using templates can dramatically improve page creation process, especially when your pages share the same structure. That way you don't need to repeat the same process over and over again. *Templates* allow you to save predefined sets of elements as a template and then reuse it when you'll need it next time.

### Templates menu

Clicking `Templates` button in WPBakery Page Builder Editor will open panel with a list of available templates and input field where you can enter a name for your new template.

1. **Save current page as a Template** – allows you to save current page structure as a template. Template name should be entered in the prompt window.
2. **Load Templates**, list of existing templates. When you want one of your existing templates to be appended to the current page, simply click that template's title. To delete template click recycle bin icon next to the template's title.

## ***Since 5.0*** Save Rows and Sections as Templates

You can save separate rows and sections as templates directly from your post layout.

![Save row or section as template](https://kb.wpbakery.com/wp-content/uploads/2018/01/row-section-save-as-template-1.png)

To save row or section as a template, open row or section param window and select settings menu on the top right corner. Click **'Save as template'** and name your new template. The template will appear under Templates window **'My Templates'**.
