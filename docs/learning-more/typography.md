***Since 8.0***

With an active support tenure, the Typography feature in WPBakery Page Builder allows you to seamlessly integrate fonts from third-party sources such as Google Fonts and Adobe Fonts.
Follow the steps below to synchronize and apply these fonts to the elements that support them:

### 1. Integrating Google Fonts

If a particular font from the Google Fonts library is missing in WPBakery Page Builder, you can easily synchronize the latest font collection.

**Steps to Integrate Google Fonts:**

1. Go to **WPBakery Page Builder** – **Typography** – **Google Fonts**.
2. Use the **Synchronize** option. This will update the existing font library within WPBakery Page Builder and bring in any new fonts added to the Google Fonts library.
3. After synchronization, the updated fonts will be available for use across the elements supporting custom fonts.

### 2. Integrating Adobe Fonts

If you have an Adobe Fonts setup for a web project, you can add these fonts directly into WPBakery Page Builder using your Adobe Web Project ID.

**Steps to Integrate Adobe Fonts:**

1. Locate your Adobe Web Project ID by visiting the [Adobe Fonts My Projects page](https://fonts.adobe.com/my_fonts#web_projects-section).
2. Copy the **Project ID** for the specific font collection you wish to integrate.
3. Go to **WPBakery Page Builder** – **Typography** – **Adobe Fonts**.
4. Paste the **Adobe Web Project ID** into the designated field and synchronize.
5. The fonts from this project will now be available within WPBakery Page Builder elements that support custom font options.
