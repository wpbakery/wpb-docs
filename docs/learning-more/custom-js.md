Unleash your coding prowess with WPBakery Page Builder's new Custom JS feature. This is a powerful feature that empowers you to customize your website javascript like never before.

With its intuitive interface, the Custom JS feature simplifies the process of adding javascript for a specific page or entire site.

To add a custom JS for the entire site, navigate to: WPBakery Page Builder -> Custom JS.

To add custom JS to a specific page, use the page settings (gear icon) within the editor toolbar.
