See how you can easily convert any WPBakery Page Builder row into full height row.

Starting from version 4.6 it is possible to add a YouTube video to the background of WPBakery Page Builder row by simply copying the link into row video background parameter. It is allowed to apply parallax effect to rows which have a video background.
