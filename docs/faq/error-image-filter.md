# When adding Image Filter I receive error: "Error while applying filter to the image. Check your server and memory settings."

It seems that the image you are adding Image Filter to is too big and uses to much resources. In order to overcome this issue use one of these solutions:

1. Reduce image size and upload it to you site
2. Increase your server memory settings
