# Is there a free version of the WPBakery Page Builder?

No, WPBakery does not offer a free license.

But if you are looking for a free alternative, we recommend giving a try to our new product: [download free Visual Composer](https://visualcomposer.com/download/) - a drag and drop website builder for WordPress that offers ready-made content elements, templates, and powerful design options.

In addition, if you are in search of a WordPress theme, Visual Composer offers a free [Starter theme](https://visualcomposer.com/visual-composer-starter-theme/) that perfectly complements the website builder.

:::note
WPBakery is not replaceable with the Visual Composer, meaning there is no migration option.
:::
