# Is there a license or plan available to use the plugin on multiple sites?

The plugin has 5 sites and 10 sites license plan which can be checked [here](https://wpbakery.com/wpbakery-page-builder-license/).

We also offer a discount for bulk purchases of 20 or more licenses. If you are interested in using the plugin on 20+ sites, please reach out to our team using the [contact form](https://wpbakery.com/wpbakery-agency-program/#agency-program-form) for information about volume discount pricing. Our team will be happy to assist you and help you find the best solution for your needs.
