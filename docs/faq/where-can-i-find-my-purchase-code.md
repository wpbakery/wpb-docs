# Where can I find my purchase code/license key?

WPBakery Page Builder license can be overviewed and managed by visiting WPBakery Support Portal – [support.wpbakery.com](http://support.wpbakery.com/). Once you activate WPBakery Page Builder you will be automatically redirected to Support Portal in order to choose/approve license you want to activate.
