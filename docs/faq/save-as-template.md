# Can I save part of the page as a template?

Starting from WPBakery Page Builder version 5.0 you can save row and section as a template. Navigate to row or section param window and under settings select **‘Save as template’**. For more detailed information visit [Templates section](/docs/docs/learning-more/templates) of the knowledge base.
