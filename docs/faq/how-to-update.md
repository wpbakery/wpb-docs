# There’s a new version of WPBakery Page Builder available, how can I get it and update it on my site?

Visit WP Dashboard -> WPBakery Page Builder -> Product License and activate your license by linking with WPBakery Support Portal – [support.wpbakery.com](http://support.wpbakery.com/). After that, you will be able to use automatic WordPress updating mechanism (with an active support tenure). When a new version of WPBakery Page Builder will be available, you should click “Update WPBakery Page Builder now” link under WPBakery Page Builder in WP Dashboard->Plugins page.
