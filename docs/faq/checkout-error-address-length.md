# I keep getting this error during checkout while purchasing the plugin: "Address fields can have a maximum length of 50 characters"

This error message typically appears when using an American Express card during the checkout process. To resolve this issue, we suggest using a Visa, Mastercard, or PayPal instead.

If you continue to experience difficulties, please reach out to our support team at support@wpbakery.com for assistance.
