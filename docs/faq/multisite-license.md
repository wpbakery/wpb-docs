# Can I use WPBakery Page Builder on several WordPress sites (Multisite/Developers license)?

The plugin offers 5 sites and 10 sites licenses which allows using it on up to 5 and 10 sites respectively.

We also offer a discount on bulk purchases of 20+ licenses. To avail it, kindly drop us a message via the [contact form](https://wpbakery.com/wpbakery-agency-program/#agency-program-form).
