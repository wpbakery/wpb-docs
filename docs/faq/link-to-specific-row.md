# Can I link to specific row of my layout?

Starting from WPBakery Page Builder version 4.5 there is an option to add ID to Row which can be used as an anchor pointer when creating a link.

In addition, ID can be used for creating more complex JS solutions which require element ID.

**Important:** When adding ID to row please make sure it is a unique value.
