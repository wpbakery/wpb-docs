# Does WPBakery Page Builder work with any WordPress theme?

WPBakery Page Builder works with all properly coded themes without any problems. What does "properly coded theme" means? There is an official [WordPress codex](http://codex.wordpress.org/) developed which states rules which need to be followed when you develop your WordPress theme. If you have developed your theme according to [WordPress codex](http://codex.wordpress.org/) then there is no problem in using WPBakery Page Builder there.

:::info
99% of all themes available at [ThemeForest](https://themeforest.net/) are compatible with WPBakery Page Builder.
:::
