# When installing WPBakery Page Builder I get error:”Fatal error: Cannot redeclare … (previously declared in …)”

It may be so that there is already an instance of WPBakery Page Builder installed on your WP site (WPBakery Page Builder has been included in your theme). In order to install standalone default WPBakery Page Builder version, you should contact your WP theme author in order to get step-by-step information on how to remove in-built WPBakery Page Builder version from your WP site and install default WPBakery Page Builder without losing extra functionality that may be added by your WP theme author.
