# Can I change element default values?

Starting from WPBakery Page Builder version 4.7 you can control default element values with Element Presets controls. In addition, it is possible to create Element Presets which can be quickly applied to an element. Element Preset controls are located in Element Parameter Window under “gear” icon in the upper right corner. For more information on how to operate with Element Preset controls see [detailed description here](/docs/learning-more/element-presets-my-elements).
