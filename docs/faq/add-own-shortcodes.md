# Can I add my own shortcodes sets?

In short – Yes. [Please check advanced documentation file](/docs/docs/inner-api) (this is something that should be done by php developer). Or if you are not so familiar with PHP/WP coding, check our new [Shortcode Mapper](/docs/docs/learning-more/shortcode-mapper) under the WP Dashboard -> WPBakery Page Builder -> My Shortcodes section.
