# Can I link to external images?

Starting from WPBakery Page Builder version 4.7 Single Image and Image Gallery elements allows choosing Image Source and specify External Image. External images can be added to via elements by entering direct link or list of links (for Image Gallery) to specific images.

**Important:** External images accept only sizes defined in pixels.
