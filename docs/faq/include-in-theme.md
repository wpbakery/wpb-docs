# Can I include WPBakery Page Builder in my theme?

In short – yes. There are few steps and rules you should be aware of before integration process. First one is that you need to purchase the extended license for each theme you want to enhance with WPBakery Page Builder  . The second that you need to receive approval from WPBakery on using WPBakery Page Builder in your theme – you can do it via WPBakery Support Portal – [support.wpbakery.com](http://support.wpbakery.com/) – by converting Extended License into In-Stock License. Please study [theme integration](/docs/docs/theme-integration-technical/theme-integration-technical) and [licensing](/docs/docs/licensing) at our knowledge base.
