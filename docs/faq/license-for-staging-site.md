# Is there a separate license available for a staging site?

No, the same license that is used for the live site can also be used on a staging site without needing to activate it.

Once the site is ready to be migrated to live, the license can then be activated on the live site. This allows for seamless testing and previewing of the site before it goes live.

If you have any further questions about using your license on a staging site, please reach out to our support team at [support.wpbakery.com](https://support.wpbakery.com/tickets) for assistance.
