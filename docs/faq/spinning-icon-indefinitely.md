# After clicking WPBakery Page Builder button I see spinning icon for indefinite time…

**First:** Make sure you are running latest WordPress version.

**Second:** This may be caused by 3rd party plugin. Deactivate all other plugins and see if WPBakery Page Builder works properly. If yes, activate other plugins one by one to determine which plugin causes conflict.
