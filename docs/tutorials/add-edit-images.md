The Single Image element allows you to add and customize an individual image on any WordPress page built with WPBakery Page Builder.

In this tutorial, you’ll learn how to select an image, set its size and alignment, control what happens when visitors click it, and customize its appearance.

## Add the Single Image element

Open the page in WPBakery Page Builder, click the plus icon and search for Single Image. Select the element to add it to your page.

## Choose the image source

The Single Image element supports three image sources:

- **Media Library** - Select an image already uploaded to WordPress or upload a new one.
- **External link** - Display an image using its external URL.
- **Featured image** - Use the featured image assigned to the current post or page.

## Choose what happens when the image is clicked

Use the **On click action** setting to control how the image behaves when a visitor selects it. You can leave the image without a click action, open the full-size or large image, display it in a lightbox, add a custom link, or enable the zoom option.

## Display the image caption

When using an image from the WordPress Media Library, you can display the caption saved for that image. Image captions are disabled by default.

## Set the image size

Choose a standard WordPress image size, such as **thumbnail**, **medium**, or **large**. You can also display the full-size image or enter custom dimensions, such as `600x500`.

## Adjust the image style and alignment

Select an available image style and choose how the image should be aligned within the page layout.

To apply additional custom styling, enter a CSS class in the **Extra class name** field.

## Customize the image design

Open **Design Options** to adjust the image’s margins, padding, border, and background. You can also select an animation for the image.

When you have finished configuring the element, save the changes and update the page.
