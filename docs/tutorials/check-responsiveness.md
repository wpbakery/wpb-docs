How to check responsiveness and switch between device types in WPBakery Page Builder.

Starting from version 9.2, you can switch between device views in both the Frontend and Backend editors. Both editors support Desktop, Tablet horizontal, Tablet vertical, Mobile horizontal, and Mobile vertical views. See [Responsive settings](/docs/building-with-wpbakery/responsive-settings) for details.
