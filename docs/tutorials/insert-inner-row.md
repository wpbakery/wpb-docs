An inner row lets you add a new column layout inside an existing column, allowing you to build more complex page sections without changing the layout of the main row. This is useful when one part of a page section needs a different structure, such as two columns inside a larger hero section.

## Add an inner row

1. Open the page in the **Frontend Editor**.
2. Add a **Row** or open an existing one.
3. Click the **plus icon** inside the column where you want the inner row.
4. Select **Row**.
5. Use **Row Layouts** to divide the inner row into columns.
6. Add content elements to each column.

For example, you can add text and an image to the left column and another text-and-image group to the right. Use the element settings and **Design Options** to adjust formatting, image size, alignment, and spacing.

You can add inner rows inside the columns of a main row. However, an inner row cannot contain another inner row.
