WPBakery image filters let you change the appearance of images selected from the WordPress Media Library. You can apply them to individual images, gallery images, and background images. WPBakery API Documentation

## Apply a filter to an image

1. Add or edit a **Single Image** element.
2. Select an image from the **Media Library**.
3. Open the image settings and choose an image filter.
4. Apply the filter, select the image, and save the element.

You can also apply a filter while selecting a new image from the Media Library.

## Apply a filter to a background image

1. Open the element’s settings and go to **Design Options**.
2. Select or edit the background image.
3. Choose and apply an image filter.
4. Save the changes.

Use the same filter across related images when you want them to have a consistent appearance.
