Starting from WPBakery Page Builder version 4.4 there is new grid elements available:

- Post Grid
- Post Masonry Grid
- Media Grid
- Masonry media Grid

Grid elements are available under WPBakery Page Builder element menu.

**Note:** "Post Grid" and "Masonry Post Grid" allows displaying posts, pages and custom posts type (Example: Woo Commerce Products) in grid format.
