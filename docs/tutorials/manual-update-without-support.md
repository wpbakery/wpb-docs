An active support tenure provides you with [additional benefits](/docs/faq/what-are-the-benefits-of-renewing-support-tenure) such as auto-updates, access to AI, template library, access to the customer center for support, etc.

However, the plugin can be updated manually if the license does not have an active support tenure. This can be done as per the Manual Updates process, which is explained [here](/docs/getting-started/update).
