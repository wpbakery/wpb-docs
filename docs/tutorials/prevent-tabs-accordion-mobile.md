In order for better user experience, WPBakery Page Builder automatically converts tab and tour elements into accordion element for mobile devices. It is possible to prevent it by applying extra class **vc_tta-o-non-responsive** to row or column which contains tab or tour elements.

**Important:** All tabs and tours within row and column will become non-responsive by applying **vc_tta-o-non-responsive** class name.
