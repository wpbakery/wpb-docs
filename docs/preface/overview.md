# Preface

<div style={{textAlign: 'center', margin: '2rem 0'}}>
  <img src="/img/wpbakery-logo-horizontal.png" alt="WPBakery Page Builder" width="250" height="59" />
</div>

WPBakery knowledge base is an informational site where you can find the latest documentation available for our [WPBakery Page Builder](https://wpbakery.com/) page builder plugin for WordPress. We consider this resource as a starting point for users to get familiar with WPBakery Page Builder usage, getting answers to the most common questions or getting into more advanced features and options.

For 3rd party developers, we've prepared a special section dedicated to WPBakery Page Builder, with a collection of advanced examples and helpful information. Studying this material will give you insight on how you can control and extend WPBakery Page Builder with your own sets of shortcodes (Content elements), develop your own WPBakery Page Builder add-ons and more.
