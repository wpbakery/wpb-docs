# WPBakery Page Builder documentation

Welcome to the WPBakery Page Builder documentation. This comprehensive guide will help you get the most out of WPBakery Page Builder, whether you're a user, developer, or theme author.

## What is WPBakery Page Builder?

WPBakery Page Builder is a drag-and-drop page builder for WordPress that lets you create and edit page layouts using frontend and backend editors, ready-made content elements, templates and responsive design controls.
